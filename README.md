# Easy Quran — downloadable content

Files the Easy Quran app downloads on demand (translations, dhikr audio).
Built by `tool/build_downloads.py` in the app repo; the app checks every file's
size and SHA-256 before using it, so do not edit files here by hand.

- `translations/albayan.json.gz` — Al-Bayan Bangla translation (Bayaan Foundation), used with permission.
- `translations/saheeh.json.gz` — Saheeh International English translation, used with permission.
- `audio/dhikr/*.mp3` — dhikr recordings for the tasbeeh screen.
